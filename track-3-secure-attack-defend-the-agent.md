# CrowdStrike

## Track 3 – Secure: Attack & Defend the Agent

Teams either build an AI agent and demonstrate how they'd defend it against prompt injection, tool misuse, or data exfiltration, or attack a provided model/agent with adversarial inputs and build a detector for the exploit. The most advanced track, and the one that maps most directly to what CrowdStrike is building with AgentWorks. Realistic scope for 8 hours: one clear exploit or defense, demoed live rather than a fully hardened system.
